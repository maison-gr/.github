# Maison GR

Maison GR is a digital product studio in Québec City. We design, build and run our own SaaS, and we build yours with the same care.

This repository holds the studio's GitHub organisation profile. The page visitors see at [github.com/maison-gr](https://github.com/maison-gr) is [`profile/README.md`](profile/README.md).

## In production

| Product | What it does | Where |
|---|---|---|
| **Resistaa** | A trilingual ADHD platform that helps people understand the block, trust what they read, and begin with one realistic action. | [resistaa.com](https://www.resistaa.com) |
| **Rehearse** | Practise the raise, the breakup, the confrontation with an AI that plays the real person, then see exactly where you lost ground. | [rehearse.maisongr.com](https://www.rehearse.maisongr.com) |
| **Signum** | Hiring, explained. A bilingual platform connecting Canadian candidates and employers through explainable matching and a built-in ATS. | [signumcareer.com](https://www.signumcareer.com) |

## Open source

**[maisongr-skills](https://github.com/maison-gr/maisongr-skills)**: engineering discipline for AI coding agents. Seven principles and thirteen skills that make an agent understand before it builds, keep its changes small, and prove the result. MIT licensed.

**[maisongr-sitemap](https://github.com/maison-gr/maisongr-sitemap)**: one sitemap, two readers. The XML search engines need, and a page in your site's own design for people, for Next.js, Astro, SvelteKit, Nuxt and Express. MIT licensed.
